# PixelOS OTA for the Lenovo TB710FU

Update feed for the unofficial PixelOS builds for the Lenovo Xiaoxin Pad Pro GT /
Yoga Tab 11.1 AI (TB710FU), read by the built-in Updater (`net.pixelos.ota`).

- `seventeen/TB710FU.json`: latest build (PixelOS 17), in the PixelOS Updater format
- `seventeen/changelogs/TB710FU.md`: changelog shown in the Updater

The zips are hosted on SourceForge. The feed is written by
[`tools/ota_release.sh`](https://github.com/Buffersolve/android_device_lenovo_TB710FU/blob/seventeen/tools/ota_release.sh)
in the device tree.

Device tree: [Buffersolve/android_device_lenovo_TB710FU](https://github.com/Buffersolve/android_device_lenovo_TB710FU)
